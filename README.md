## 管理与共享文件

页尾“物料管理”进入admin.html。管理员输入管理密码，后台验证后建立有限时长会话。密码仅在请求中传至后台，既不写入前端，也不保存到浏览器；数据库只保存不可直接使用的口令散列。连续失败尝试会暂停登录。

沿用Supabase原项目 https://axnadxkfuemmktffcehb.supabase.co ，资料存于gratitude-materials。管理端由gratitude-admin Edge函数验证会话后处理上传、发布与下架。管理会话只在本标签页有效；公开访客无需登录，不能上传或修改。后台密钥与管理密码均禁止进入前端或仓库。

支持PDF、图片、Word、Excel和PPTX，单文件20MB以内。hmall图和市场报告在专业服务区展示，其他文件进入补充资料；hmall新版发布后旧版退出目录。公共文件下架仅隐藏列表，原公开下载地址仍有效。

schema.sql为基础权限，admin-pin.sql为管理员认证结构。真实口令散列单独通过项目所有者连接登记，不包含在源码。已用真实PDF完成后台登录、上传、公开下载及上下架验证；真实hmall图仍由项目组按实际文件更新。
