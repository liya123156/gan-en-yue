## 已明确的使用方式

- 销售中心无需登录浏览、复制内容、定制和下载贺卡。
- 称呼、正文和署名仅保留在使用者自己标签页的草稿中，不上传至数据库，不改动公共模板。
- 线上PNG为1080×1440；线下A6横版为148×105mm，可下载高清PNG和PDF。
- hmall图一次本地文件上传；市场报告由业务管理部门提供，再由Liya上传；成交信息由伙伴编辑实际事实。
- 管理上传只向被明确登记的Liya管理员开放。
- 大区总支持按单店当月送出量取最高档，0—10份0元，11—20份100元，此后每档增加100元，51份及以上500元。每店每月最高500元，档位不累加。
